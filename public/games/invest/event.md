## 板块事件
各板块事件发生时只影响本板块所有股票
世界事件发生时，相关偶然板块事件会被触发
带*的事件不是偶然事件，是板块稳定发生的事件

### 魔药医药板块
【药剂突破】：
触发时，魔药医药板块：3n+1 → 4n+1

*【副作用危机】：
连续上涨3次后：下一次偶数 n/2 → n/3

### 炼金造物板块
【炼金变异】
奇数3n+1 → 5n+1，偶数n/2 → n/4
【炼金爆炸】
价格直接归1，退出市场

### 佣兵战力板块
【战争状态】
3n+1 → 6n+1
【和平裁军】
n/2 → n/3，保留一位小数

### 矿产资源板块
*【资源枯竭】
每上涨一次，depletion += 1
depletion >= 10时，偶数暴跌：n/2 → n/5，保留一位小数

【发现矿脉】
强制奇数上涨

### 餐饮食饮板块
*【民生需求】
偶数特性稳定为：n/2 → n*0.75
【瘟疫事件】
强制偶数（即要影响的股价若为奇数，强制-1）

### 魔法魔导板块
【魔力涌动】
3n+1 → 7n+1
【魔力枯竭】
n/2 → n/4
【禁术暴走】
股价翻10倍

### 商贸商旅板块
与佣兵板块联动
【和平裁军】触发*【贸易繁荣】
3n+1 → 4n+1
【战争状态】触发*【道路封锁】
n/2 → n/4

### 建筑城建板块
*【城市扩张】
连续2次偶数时：不会继续跌，而是价格冻结2周期

【地产泡沫】
股价/4

### 宠物魔兽板块
【稀有魔兽】
股价*5 

【兽潮失控】
股价/5


## 世界事件系统
每周期会有50%概率触发以世界事件，各世界事件发生概率一样，世界事件的本质是偶然板块事件组合
### 魔潮爆发
建筑城建板块强制跌一次
【药剂突破】、【稀有魔兽】、【魔力涌动】、【炼金变异】

### 王国战争
【战争状态】（【道路封锁】联动）、【发现矿脉】

### 巨龙袭城
建筑城建板块强制跌一次
【兽潮失控】、【战争状态】（【道路封锁】联动）、【禁术暴走】、【炼金爆炸】

### 世界瘟疫
【药剂突破】、【瘟疫事件】、【魔力枯竭】

### 无事发生
【和平裁军】（【贸易繁荣】联动）

## 股价最终执行顺序
执行世界事件 -> 执行偶然板块事件 -> 执行联动 -> 执行非偶然板块事件 -> 执行考拉兹序列 -> 检查退市
